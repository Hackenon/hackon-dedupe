# DIY clearance search — "HackOn"

*Run 2026-11-21. A free, do-it-yourself first pass. **Not a legal clearance or legal advice** —
this used third-party trademark mirrors (Justia/Markinton) and public web/app-store searches, not
the official USPTO database. Before filing, re-run on the official Trademark Search at
tmsearch.uspto.gov and get an attorney opinion.*

## What I searched
- Word-mark databases for **HACKON** and look/sound-alikes (HACKCON, HACKERNON, HACKON + variants).
- App stores and the web for a product called **HackOn** in software/media.
- Domains.

## Findings

### Trademarks — no exact "HACKON" found
No registered or pending **"HACKON"** word mark turned up. The nearby "Hack*" marks are either in
**different goods/services** or are **dead/cancelled**:

| Mark | Status | Field |
|---|---|---|
| **HACKCON** | **Cancelled** (Section 8) | — |
| **HACKERNON** | **Dead/cancelled** | Computer security consultancy (Class 42) |
| HACKINGTONS | Registered | (coding education) |
| HACKERX | Registered | events/recruiting |
| HACKED / HACK ATTACK / HACKER HOUR / HACKAGEDDON | Registered | security, events, advertising |
| HACKNOWN | Abandoned | — |

Takeaway: the "Hack*" neighborhood is busy, but **nothing is an exact "HackOn" in downloadable
software (Class 9)**, and two of the closest-sounding ones (HACKCON, HACKERNON) are no longer live.

### Product / app uses — nothing colliding
- **hackOS** — a hackathon operations app (HackUDC). Different product and purpose.
- **HackStore** / **HackThe.Store** — Mac app-store alternatives / ASO tools. Different goods.
- **Hack.Hub** — a hacking-themed game. Different goods.
No existing **HackOn** media/dedup/library product found.

### Domains
- **hackon.tech** — already registered/in use by someone else.
- **hackon.com** — showing as **expired / pending release** (per the registrar page), so it may
  become available to register. (A domain is not a trademark right — see the licensing doc.)

## Assessment (non-legal)
- **No obvious exact-match blocker** for "HackOn" in Class 9 downloadable software.
- **Registrability looks fine:** "HackOn" is suggestive/arbitrary for photo/video dedup software
  (it doesn't describe the product), which is the registrable kind of mark. The descriptive tail
  "Photo & Video DeDupe" would be **disclaimed**.
- **Main residual risk is "likelihood of confusion"** within the crowded "Hack*" field — that's a
  judgment call an examining attorney (and ideally our own attorney) makes, not something a DIY
  search settles. The dead status of HACKCON/HACKERNON helps.

## The exact terms to re-run officially (for the lawyer / tmsearch.uspto.gov)
Search each in **Class 9** (downloadable software) and **Class 42** (if we host it as a service):
- `HACKON`, `HACK ON`, `HACK-ON`
- Phonetic/visual equivalents: `HAKON`, `HACKAWN`, `HACKKON`, `HACON`, `HAKKON`
- Broader field scan: `HACK*` in Classes 9 and 42 to eyeball close live marks
- Design-mark search if we file a logo version
Also check: state trademark registries, common-law (web, app stores, GitHub, Product Hunt), and the
`.com`/`.app` domain + social handles for `hackon` / `hackondedupe`.

## Recommendation
- The DIY pass is **clean enough to proceed** with "HackOn" to the next step.
- Use **™** now. Before spending on a filing, have an attorney run the official search + a
  confusion opinion (the crowded Hack* field is exactly where that opinion earns its fee), then file
  **intent-to-use** in Class 9. See `uspto-trademark-clearance.md` for fees and process.
