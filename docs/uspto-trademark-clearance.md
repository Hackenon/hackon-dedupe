# USPTO trademark clearance & cost — for "HackOn"

*Researched 2026-11-21. Plain-English summary to plan with a lawyer. **Not legal advice.**
Fees change; confirm on uspto.gov before filing.*

## What we'd register
- Register the **distinctive word: "HackOn"** (the ownable part). The descriptive words
  "Photo & Video DeDupe" would almost certainly have to be **disclaimed** (no exclusive rights to
  them) — that's normal and fine; you still own "HackOn."
- Likely **one class: Class 9** (downloadable software). If we also sell it as a hosted/online
  service, add **Class 42** (software as a service). Each class is a separate fee.
- Because we're **not selling yet**, the path is an **Intent-to-Use (ITU, §1(b))** application: it
  reserves the mark now, and we prove actual use later (a "Statement of Use") before it registers.
  If we're already selling when we file, it's a use-based (§1(a)) application instead.

## The fees (USPTO, current as of the 2025 fee reform)
As of **Feb 18, 2025** the old TEAS Plus/Standard tiers were replaced by **one "base application"
fee of $350 per class**, with surcharges if the filing is sloppy:

| Fee | Amount | Notes |
|---|---|---|
| **Base application** | **$350 / class** | The core filing fee. |
| Insufficient-information surcharge | +$100 / class | If the application is missing required info — **avoidable** by filing a complete application. |
| Free-form description surcharge | +$200 / class | If you write your own goods/services wording instead of picking from the USPTO's ID Manual — **avoidable** by using the ID Manual. |
| Statement of Use (ITU only) | $150 / class | Paid later, once the app is actually on sale, to complete an intent-to-use registration. |
| (Later) Renewal — §9, every 10 years | $325 / class | Plus a §8 "declaration of use" between years 5–6 and at each renewal. |

**So the realistic USPTO cost for HackOn (1 class, done cleanly):**
- **~$350** to file (use the ID Manual, file complete → no surcharges).
- **+$150** later for the Statement of Use if we file intent-to-use now (likely).
- **~$500 total in government fees** to get from filing to registration on the ITU path, one class.
- Two classes (9 + 42) roughly doubles the per-class fees.

## Attorney vs do-it-yourself
- A US applicant **can** file without a lawyer. An attorney is **not required** for US-based filers
  (it is required for foreign-domiciled applicants).
- Typical attorney fees for a straightforward mark: **~$500–$2,000** on top of the USPTO fees. Worth
  it here because the **"Hack*" field is crowded** (HackerOne, HackNotice, Hacky, etc.), so a
  likelihood-of-confusion refusal is a real risk, and an attorney both runs a proper clearance
  search and writes the goods/services to dodge surcharges and refusals.

## Clearance search (do this BEFORE filing)
"Clearance" = making sure "HackOn" is actually available, so we don't pay to file and then get
refused or sued. Levels:
1. **Free DIY** — search the USPTO's trademark search system (the tool that replaced TESS) for
   "HackOn" and close variants in Classes 9 & 42; plus common-law checks (web, app stores, business
   directories, domains). *(My preliminary pass: no exact "HackOn" software mark, but a crowded
   "Hack*" field and hackon.tech/.com already taken — see the trademark-and-licensing doc.)*
2. **Professional clearance search** — a search firm or attorney runs a full search (federal, state,
   common-law) and gives an opinion. Typically **~$300–$1,000**. Recommended given the crowded field.

## The process, start to finish
1. **Clearance search** (above).
2. **File** the application (ITU §1(b) if not yet selling), one class, using ID Manual descriptions.
3. **Examination** by a USPTO examining attorney — takes **several months to ~a year+**; the 2025
   reforms aim to cut this but it's still slow.
4. **Office actions** (if any) — e.g. a refusal for likely confusion or a request to disclaim
   "Photo & Video DeDupe"; you respond.
5. **Publication** for opposition (30 days for others to object).
6. **ITU only:** Notice of Allowance → start selling → file the **Statement of Use** ($150/class).
7. **Registration** (the ® symbol; before that you can use ™).
8. **Maintain** it: §8 declaration years 5–6, §9 renewal at year 10 ($325/class), then every 10 yrs.
